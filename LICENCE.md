## 🧩 About

**Dark and Darker Companion** is a curated list of Dark and Darker open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot tracker, map notes
- **Quality-of-Life Helpers** — gear catalog, stash organizer, overlay notes
- **Research Notes** — dungeon layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Map Notes — annotate dungeon layouts for study
- Loot Tracker — keep track of found items in a run
- Stash Organizer — sort inventory and gear loadouts
- Route Notes — record and review run paths

### Wallhack
- Gear Catalog — browse weapons, armor, and accessories
- Class Notes — organize class builds and perks
- Overlay Skins — improve on-screen visibility

### Aimbot
- Loadout Notes — plan equipment before a run
- Trade Notes — track merchant prices for study
- Keybind Helper — organize hotkeys in one place
